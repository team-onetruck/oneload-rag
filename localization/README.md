# 임시 위치 데이터 (답사 전)

현장 사진을 아직 찍을 수 없어서, **공식 자료로 만든 임시 데이터**로 사진 위치 인식의 매칭 단계를 개발·시연하기 위한 폴더입니다. 검토가 끝나면 `oneload-data`(지도)와 `oneload-qa`(평가)로 옮깁니다(요청 RQ-16).

## 왜 사진이 없어도 되나

위치 인식은 사진과 사진을 비교하지 않고, 두 단계로 나뉩니다.

1. VLM이 사진에서 **글자만 읽습니다** (R2 `LLMVision`).
2. 읽은 글자를 **노드별 표지판 문구와 비교**합니다 (백엔드 `match_location`, R2 `rank_location`).

이 폴더는 2단계용 데이터입니다. 1단계(VLM이 실제 표지판을 얼마나 잘 읽는지)는 현장 사진으로만 잴 수 있습니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `seoul-station.landmarks.yaml` | 노드별 특징 카드: 표지판 문구(한 줄 = 한 항목), 출처, 상태(`desk` / `placeholder` / `photo` / `field`), 헷갈리는 이웃 노드, 메모. 끝에 지도에 없는 **제안 노드·경로**와 **지도와 다른 점**(R4용) |
| `cases.yaml` | 합성 입력 24개: "사진에서 이 글자들이 읽혔다" → 정답 노드 또는 `NO_MATCH` (깨끗한 문구, 일부만 읽힘, 오타, 애매함, 잡음, 관계없는 사진) |
| `evaluate.py` | 같은 입력으로 세 조합을 비교 (백엔드 매처 + 현재 지도, 백엔드 매처 + 카드, R2 매처 + 카드) |

```sh
uv run python localization/evaluate.py     # 옆 폴더의 oneload-data, oneload-backend, oneload_agent 사용
```

## 결과 (2026-10-22)

위치가 있는 케이스 20개와 `NO_MATCH` 케이스 4개 기준입니다.

| 조합 | top-1 | top-3 | NO_MATCH |
| --- | --- | --- | --- |
| 백엔드 `match_location` + 현재 지도 landmarks | 4/20 | 4/20 | 4/4 |
| 백엔드 `match_location` + 특징 카드 | 15/20 | 15/20 | 4/4 |
| R2 `rank_location` + 특징 카드 | 18/20 | 20/20 | 4/4 |

**결과를 읽을 때 주의할 점**
- 케이스 문구를 카드에서 가져왔기 때문에 결과가 **후하게** 나옵니다.
- 이 표에서 알 수 있는 것은 두 가지입니다.
  - 카드가 지도와 맞는지
  - 일부만 읽힌 글자나 오타에 매처가 버티는지 (백엔드 정확 일치 ✗, R2 부분·오타 일치 ✓. 결정 D-26 비교 근거)
- **실제 서울역 정확도는 아닙니다.**

## 사진 근거 추가 (2026-10-23)

- 공개 사진·영상·스트리트뷰 속 표지판 문구를 `status: photo`로 넣었다(노드 7곳). 근거는 `research/photos-2026-10-23.md`.
- 지도에 아직 없는 지점 3곳(직통 하차 환승 구역, B3 15번 출구 개찰구, B6 에스컬레이터)과 경로 4개를 `proposed_nodes`·`proposed_routes`로 적었다. R4가 지도에 넣으면 `nodes`로 옮긴다.
- 합성 케이스(`cases.yaml`)는 그대로라 위 표의 결과도 같다.

## 한계와 다음 단계

- **`desk` 문구의 정확성**: 공식 안내도의 시설 이름입니다. 실제 표지판 문구나 위치와 다를 수 있습니다.
  - 구글 스트리트뷰(AREX 서울역 안내 페이지에 층별 링크 있음)로 보면서 받아 적으면 더 가까워집니다. 이미지는 저장하지 않습니다.
- **문구가 없는 노드**: `express-gates`, `allstop-gates`는 공식 자료에 표기가 없어 비어 있습니다.
- **현재 지도 값**: `ktx-hall`과 1·4호선 개찰구는 현재 지도의 임시값(`placeholder`)입니다.
- **답사 후**: 같은 형식으로 `status: field`로 바꾸고, 실제 사진은 QA `eval/photo_manifest.csv`로 평가합니다.
