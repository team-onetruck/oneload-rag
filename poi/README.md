# 장소 별칭 사전 (R3 초안)

API 명세 v0.3 1장에서 R3 책임으로 정한 "장소 별칭 사전"입니다. 반영은 `oneload-data` 지도의 POI `aliases`에서 R4가 합니다.

## 왜 필요한가

백엔드 `MapData.search_pois`는 **Agent가 만든 짧은 장소 표현(poi_query)이 POI 이름이나 별칭 안에 통째로 들어 있을 때만** 그 POI를 찾습니다(소문자 부분 문자열 일치). 그래서 "airport train ticket", "직통열차 타는 곳"처럼 별칭에 없는 표현은 아예 못 찾습니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `seoul-station.aliases.yaml` | POI별 추가 별칭과 출처(`arex-map` 공식 안내도, `floor-sign` 층별안내판, `phrase` 여행객 표현). 아직 지도에 없는 장소 5곳 제안(고객안내센터, 트래블센터, 도심공항터미널, 1·4호선 갈아타는 곳, 티머니타운) |
| `queries.yaml` | 질문 38개 → 기대 POI (애매하면 둘 다 나와야 정답, 지도에 없는 곳은 아무것도 안 나와야 정답) |
| `check.py` | 현재 지도와 별칭을 넣은 지도로 `search_pois`를 돌려 비교 |

```sh
uv run python poi/check.py
```

## 결과 (2026-10-22)

| | 기대한 POI만 정확히 찾은 질문 |
| --- | --- |
| 현재 지도 | 21 / 38 |
| 별칭 추가 후 | 38 / 38 |

## 주의

- **부분 문자열 일치라서 별칭이 다른 질문을 가로챌 수 있습니다.**
  - 예: "직통열차 고객안내센터"를 직통열차 표 사는 곳의 별칭으로 넣으면, "고객안내센터"라고만 물어도 B2 직통열차 표 사는 곳으로 갑니다.
  - 그래서 이 별칭은 뺐습니다.
  - 별칭을 추가하면 꼭 `check.py`를 돌리세요.
- 질문 목록은 사람이 쓴 표현 예시입니다. 실제 Agent가 만드는 poi_query 로그가 쌓이면 다시 고릅니다.
