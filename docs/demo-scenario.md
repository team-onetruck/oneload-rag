# 시연 시나리오 초안 (R3, 2026-10-23)

팀이 시연 방식을 정할 때 쓰는 초안입니다. 메인 시나리오는 **외국인 여행객이 공항철도로 서울역에 도착해 1·4호선이나 KTX로 갈아타는 것**, 그리고 반대로 **서울역에서 공항철도 표를 사는 것**입니다.

- 질문별 상태는 실제 LLM(gpt-4o-mini)으로 돌려 본 결과입니다: `eval/agent-live-2026-10-23.md`
  - ✅ 지금 됨 · ⚠️ 되지만 보완 필요 · ❌ 지금 안 됨
- 근거 문서는 `knowledge/`의 문서 ID입니다. 화면에는 출처와 확인 날짜가 함께 나옵니다.

## 발표에서 말할 때 주의

- **사진 위치 인식 정확도는 미측정입니다.** 현장 사진 정답이 0건입니다. 시연 사진이 재현 표지판이나 공개 사진이면 그렇게 밝힙니다.
- **문서는 공식 출처만 씁니다.** 전화 확인 전인 내용(직통 하차 후 게이트·발매기 등)은 서비스가 말하지 않습니다.
- **지도 위치·거리는 답사 전 임시값입니다.**
